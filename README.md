> 🚧 **In active development.** This repository is being built out — a modern, 3D-interactive portfolio website for an AI/ML engineer. The plan below is the target; code is being added incrementally.

## 💡 The Idea

A portfolio that shows, not just tells: a 3D-interactive experience where visitors explore projects, skills, and a **live AI agent console** — a working demo of the kind of AI systems I build for clients.

## 🎯 Planned Features

- 🌐 **3D-interactive hero & scenes** — React Three Fiber / Three.js visuals with smooth camera motion
- 🤖 **Live AI agent console** — an interactive demo where visitors can chat with an AI assistant about the portfolio
- 🎞️ **Animated skills grid** — Framer Motion transitions and scroll-triggered reveals
- 💼 **Project showcase** — featured AI automation, chatbot, and n8n workflow projects
- 📱 **Fully responsive** — works on desktop and mobile, with reduced-motion support

## 🛠️ Planned Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js (App Router) + React |
| 3D | React Three Fiber + Three.js |
| Animation | Framer Motion |
| Styling | Tailwind CSS |
| AI demo | OpenAI API (via Next.js API route) |
